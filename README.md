# Field

Playable beat studio in the browser. Loops, drums, keys, guitar, and scenes.

## Run

```bash
npm install
npm run dev
```

Open the app, tap **Enable sound**, then play.

## Scenes

Lofi, Hop, Trap, Under, Melt, Emo, Bounce, Det, Memph.

Stack drums, bass, keys, and guitar clips. Mix and the drum grid sit behind the extra panels.
